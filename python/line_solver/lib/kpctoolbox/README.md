# KPC-Toolbox

This is a Python port of the KPC-Toolbox originally implemented in MATLAB
and located at `matlab/lib/kpctoolbox/` in the LINE solver repository.

The KPC-Toolbox provides methods for:

- **Trace analysis**: Statistical analysis of measurement traces
- **MMPP fitting**: Fitting Markov-Modulated Poisson Processes to traces
- **KPC fitting**: Kronecker Product Composition fitting of MAPs
- **MVPH analysis**: Matrix-variate PH distribution analysis
- **APH utilities**: Acyclic Phase-type distribution construction
- **CTMC/DTMC utilities**: Continuous and discrete time Markov chain solvers
- **MAP utilities**: Markovian Arrival Process operations

## Origin

This code is a derivative work ported from MATLAB to Python for use in the
native Python implementation of the LINE solver. The original MATLAB source
is located at `matlab/lib/kpctoolbox/` in the LINE solver repository.
